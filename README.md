# דאשבורד מלאי ולוגיסטיקה

**לצפייה:** https://e37dey.github.io/inventory-logistics-dashboard/

דאשבורד למחסן חלקי חילוף בשלושה מחסנים (חיפה, אשדוד, עפולה): מצב מלאי, התראות מלאי נמוך עם כמות מוצעת להזמנה, ומעקב משלוחים. נתוני דמה בלבד.

עבודת בית לשיעור 3 בקורס AiDO. נבנה עם Claude Code לפי השיטה מהשיעור:
- [SPEC.md](SPEC.md): מה בונים, בשביל מי, ומה זה ״גמור״. נכתב ב-commit הראשון, לפני כל קוד.
- [Practice.md](Practice.md): איך עובדים, כולל שמירה ועדכון ב-GitHub.
- [CLAUDE.md](CLAUDE.md): טוען את שני הקבצים בכל סשן.
