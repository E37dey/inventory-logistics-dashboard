# דאשבורד מלאי ולוגיסטיקה

דאשבורד למחסן חלקי חילוף בשלושה מחסנים (חיפה, אשדוד, עפולה): מצב מלאי, התראות מלאי נמוך עם כמות מוצעת להזמנה, ומעקב משלוחים. נתוני דמה בלבד.

עבודת בית לשיעור 3 בקורס AiDO, נבנה עם Claude Code לפי השיטה מהשיעור:
- [SPEC.md](SPEC.md): מה בונים, בשביל מי, ומה זה ״גמור״.
- [Practice.md](Practice.md): איך עובדים, כולל שמירה ועדכון ב-GitHub.

## סטטוס
- [x] נתוני דמה קבועים (seed) ולוגיקה: סטטוס פריט, כמות להזמנה, עיכוב משלוח, מדדים, סינון
- [x] ארבעה מדדים וטבלת מלאי עם סינון לפי מחסן, קטגוריה וסטטוס, וחיפוש
- [x] ״להזמנה עכשיו״: פריטים שאזלו קודם, כמות מוצעת לפי MOQ, עלות משוערת, וסימון להזמנה שלא נכפל
- [x] מעקב משלוחים נכנסים ויוצאים: מתעכבים ראשונים ובאדום, ימים לאיחור או להגעה
- [x] גרפים: שווי מלאי לפי קטגוריה, משלוחים לפי סטטוס
