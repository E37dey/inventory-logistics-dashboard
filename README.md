# דאשבורד מלאי ולוגיסטיקה

**לצפייה:** https://e37dey.github.io/inventory-logistics-dashboard/

חדר בקרה למחסן חלקי חילוף בשלושה מחסנים (חיפה, אשדוד, עפולה). ארבעה מסכים:
- **סקירה:** מדדים עם מגמה ושינוי, מפת רשת, ״דורש טיפול״, מחסנים, תנועה יומית ויומן אירועים.
- **מלאי:** טבלה ממוינת וחיפוש, עם ימי מלאי, תאריך אזילה, ABC ומגירת פריט.
- **משלוחים:** לוח לפי מצב, עם סינון נכנס ויוצא.
- **ספקים:** אחוז אספקה בזמן, זמן אספקה ממוצע ומשלוחים פתוחים.

בנוסף יש סל הזמנה מקובץ לפי ספק, עם ייצוא CSV לצוות הרכש. כל הנתונים הם נתוני דמה.

עבודת בית לשיעור 3 בקורס AiDO. נבנה עם Claude Code לפי השיטה מהשיעור:
- [SPEC.md](SPEC.md): מה בונים, בשביל מי, ומה זה ״גמור״. נכתב ב-commit הראשון, לפני כל קוד. גרסה 2 נוספה ל-SPEC ב-PR נפרד לפני הקוד שלה.
- [Practice.md](Practice.md): איך עובדים, כולל שמירה ועדכון ב-GitHub.
- [CLAUDE.md](CLAUDE.md): טוען את שני הקבצים בכל סשן.
